# Как добавить новое приложение

1. Добавить иконку и медиафайлы в `assets/`.
2. Создать папку `<app-slug>/` с файлом `index.html` по образцу `warehouse-sort/index.html`.
3. Добавить карточку в `_data/apps.yml`. Главная страница подхватит её автоматически.
4. Если приложение собирает иной набор данных, создать для него отдельную политику конфиденциальности.

Не менять адрес `/privacy.html` без обновления App Store Connect.
