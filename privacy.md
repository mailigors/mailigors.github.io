# Warehouse Sort — политика конфиденциальности

**Дата обновления: 7 октября 2026 года**

Эта политика описывает обработку данных в игре Warehouse Sort для iOS и на сайте поддержки. За обработку обращений и работу приложения отвечает разработчик Warehouse Sort. Контакт по вопросам конфиденциальности: [igorsoloviov77@gmail.com](mailto:igorsoloviov77@gmail.com).

## 1. Данные игры на устройстве

Warehouse Sort сохраняет на вашем устройстве прогресс: открытые уровни, результаты, звёзды, игровую валюту, награды, оформление склада, текущую игровую сессию и настройки языка, звука и доступности. Эти данные нужны для продолжения игры и сохранения выбранных настроек.

У разработчика нет собственного сервера для хранения вашего игрового прогресса. В текущей версии не реализована собственная синхронизация прогресса между устройствами. Резервные копии устройства могут включать данные приложения в соответствии с вашими настройками сервисов Apple.

Для основной игры отдельная регистрация не требуется. Приложение не запрашивает доступ к контактам, камере, микрофону, фотографиям или геолокации устройства. Отдельный журнал тестирования игрового процесса в публикационной версии отключён. Собственная служба отправки игровых событий в систему аналитики не используется.

## 2. Game Center

Если вы используете Game Center, приложение передаёт в сервис Apple игровые результаты и сведения о достижениях, связанные с вашей учётной записью Game Center. Это позволяет показывать результаты в таблицах лидеров и учитывать достижения. Видимость вашего игрового профиля и результатов зависит от настроек Game Center.

Игра не получает пароль вашего Apple Account. Основной игровой процесс доступен без входа в Game Center. Обработка данных сервисом описана в [Game Center и конфиденциальность](https://www.apple.com/legal/privacy/data/ru/game-center/).

## 3. Реклама

В игре используется Yandex Mobile Ads и медиация рекламы с адаптером Unity Ads. Рекламный SDK также использует AppMetrica для служебных событий и диагностики. Реклама может показываться в паузах между попытками, а реклама с вознаграждением — после вашего выбора соответствующего действия.

При подключении к рекламным сервисам они могут обрабатывать IP-адрес, технические сведения об устройстве, системе и приложении, идентификаторы установки или устройства, сведения о рекламных запросах, показах и взаимодействиях с рекламой, служебных сеансах приложения, сбоях, производительности и технической диагностике. Состав данных зависит от поставщика, режима обработки и разрешений iOS. Данные используются для доставки рекламы, её измерения, выдачи вознаграждений, работы сервисов и предотвращения недействительных показов и мошенничества.

Приложение передаёт в Yandex Mobile Ads признак возрастных ограничений до загрузки рекламы; запросы выполняются в режиме, предназначенном для неперсонализированной рекламы. Приложение не запрашивает разрешение на отслеживание через App Tracking Transparency и не запрашивает доступ к рекламному идентификатору IDFA. Это не исключает техническую обработку данных, необходимую для работы рекламы.

Подробнее об обработке данных и доступных вариантах управления ими:

- [Политика конфиденциальности Яндекса](https://yandex.ru/legal/confidential/).
- [Политика Unity для игроков и пользователей приложений](https://unity.com/legal/game-player-and-app-user-privacy-policy).

При наличии в рекламном объявлении кнопки конфиденциальности поставщика вы можете воспользоваться ею для просмотра доступных настроек и запросов, связанных с данными.

## 4. Обращения в поддержку

Если вы пишете нам по электронной почте, мы получаем ваш адрес, текст обращения и добровольно приложенные файлы. Они используются для ответа, диагностики описанной проблемы и обработки запросов о конфиденциальности. Переписка обрабатывается также почтовым сервисом, через который она отправлена и получена.

Не присылайте пароли, платёжные данные или другие сведения, которые не нужны для решения проблемы. Эти данные не требуются для поддержки игры.

## 5. Сайт поддержки

Сайт размещён на GitHub Pages. Для доставки страниц и защиты инфраструктуры GitHub может обрабатывать IP-адрес и технические сведения о запросах посетителей. См. [политику конфиденциальности GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

На странице поддержки не установлены собственные рекламные или аналитические счётчики. При переходе по внешней ссылке действуют правила соответствующего сайта.

## 6. Передача и защита данных

Данные передаются поставщикам сервисов, описанным выше, в объёме, необходимом для их функций. Разработчик не продаёт переписку поддержки и не использует её для рекламных рассылок. Сведения могут быть раскрыты, если этого требует применимое законодательство.

Поставщики сервисов могут обрабатывать данные за пределами вашей страны; условия передачи и защиты описаны в их политиках. Для данных под контролем разработчика доступ ограничивается задачами поддержки и обслуживания игры. Ни один способ хранения или передачи данных не обеспечивает абсолютную защиту.

## 7. Сроки хранения и удаление

Игровые сохранения хранятся на устройстве, пока существуют данные приложения. Чтобы удалить их, удалите приложение через настройки iOS именно с удалением данных, а не с помощью функции «Сгрузить приложение». Данные в резервных копиях устройства управляются отдельно средствами Apple. Удаление приложения не удаляет автоматически результаты Game Center или данные у рекламных поставщиков.

Переписка поддержки хранится столько, сколько необходимо для решения обращения и связанных вопросов, а затем удаляется, если дальнейшее хранение не требуется по закону. Вы можете запросить её удаление по почте поддержки. В запросе достаточно указать адрес, с которого вы обращались, и соответствующую переписку.

Сроки хранения данных Apple, Яндексом, Unity и GitHub определяются их политиками. Запросы об удалении данных, находящихся у этих поставщиков, можно направлять им через указанные выше страницы. Разработчик не имеет прямого доступа ко всем данным, которые они обрабатывают.

В зависимости от применимого законодательства вы можете запросить доступ, исправление или удаление данных, ограничение обработки, возразить против неё или отозвать ранее предоставленное согласие. По данным под контролем разработчика напишите на [igorsoloviov77@gmail.com](mailto:igorsoloviov77@gmail.com). По данным стороннего сервиса воспользуйтесь его средствами управления конфиденциальностью. Отзыв согласия не влияет на правомерность обработки до его отзыва. Если это предусмотрено законом, вы также можете обратиться в уполномоченный орган по защите данных.

Если родитель или законный представитель считает, что ребёнок сообщил разработчику персональные данные, он может написать в поддержку для рассмотрения вопроса и удаления таких данных.
